# 11. Tema, paneles y atajos

[← Volver al README](../../README.md)

## Tema claro y oscuro

El botón sol/luna de la cabecera cambia el tema con una transición circular que nace en el botón, al estilo Telegram. El modo oscuro usa el azul noche de Telegram. Sin una elección guardada, la app sigue el tema del sistema. Si el sistema pide reducir el movimiento, el cambio es inmediato.

## Paneles y secciones plegables

- Los paneles laterales se pliegan a un riel estrecho: <kbd>[</kbd> pliega el izquierdo y <kbd>]</kbd> el derecho (no actúan mientras escribes).
- Cada grupo con encabezado y chevron se pliega o despliega.
- Ambos recuerdan su estado.

## Editor de código

Los bloques de SQL usan Monaco, el editor de VS Code: pestaña con el nombre del archivo, números de línea, resaltado, plegado, búsqueda (<kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>F</kbd>) y barra de estado. Al editar, autocompleta tablas, columnas (escribe `tabla.`), vistas, funciones y enums del esquema.

## Atajos del diagrama

| Atajo | Acción |
|---|---|
| <kbd>Ctrl</kbd> + clic derecho (o <kbd>⌘</kbd> + clic derecho) | Menú de acciones |
| <kbd>Shift</kbd> + <kbd>F10</kbd> | Menú del elemento seleccionado |
| <kbd>T</kbd> / <kbd>N</kbd> | Nueva tabla / nota |
| <kbd>V</kbd> / <kbd>H</kbd> | Seleccionar / mover el lienzo |
| <kbd>F2</kbd> / <kbd>Enter</kbd> | Renombrar o editar (en un trigger, abre su modal) |
| <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>C</kbd> / <kbd>V</kbd> / <kbd>D</kbd> | Copiar / pegar / duplicar |
| <kbd>Supr</kbd> | Eliminar la selección |
| <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>Z</kbd>, <kbd>⇧</kbd> + <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>Z</kbd> | Deshacer / rehacer |
| <kbd>Esc</kbd> | Quitar la selección |
